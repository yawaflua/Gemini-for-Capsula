# Участие в разработке

Спасибо, что хотите помочь проекту!

## Язык

Просьба писать на русском (issues, pull requests, сообщения коммитов, комментарии в коде),
но также разрешается английский.

## Ветки

Все пуши и pull requests от сообщества проводятся в ветку `stage`, откуда уже производится пуш в `master`.
Pull requests напрямую в `master` не принимаются.

## Как предложить изменение

1. Сделайте форк и создайте ветку от `stage`.
2. Внесите изменения и проверьте, что всё собирается и тесты проходят:
   ```bash
   go build ./... && go test ./...
   ```
3. В первом pull request добавьте себя в [AUTHORS](AUTHORS).
4. Откройте pull request в ветку `stage` с кратким описанием: что меняется и зачем.

## Сообщить о проблеме

Используйте шаблон issue «Сообщение об ошибке» — он попросит указать версии сервера и агента,
логи и шаги для воспроизведения.
